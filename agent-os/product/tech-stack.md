# Tech Stack

## Frontend

- **Framework:** Next.js (App Router)
- **UI Components:** shadcn/ui
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Design System:** Stitch MCP

## Backend

- **Runtime:** Next.js API Route Handlers (same repo, full-stack)
- **Auth:** WorkOS (sign in, session management, middleware guard)
- **ORM:** Prisma

## Database

- **Production:** PostgreSQL via Supabase
- **Local development:** PostgreSQL via Docker

## Other

- **Deployment:** Vercel
